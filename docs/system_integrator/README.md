# System Integrator Guide

本目录面向系统集成者，帮助你将 Universal Arm Controller 集成到完整机器人产品或产线系统中。

## 推荐阅读顺序

请**按照以下顺序**阅读，这是从"系统评估"到"成功集成"的完整路径：

### [SYSTEM_INTEGRATION.md](SYSTEM_INTEGRATION.md)
**系统集成完整指南**

分为三个层次：
- **第一层**：快速系统适配评估（5 分钟判断系统是否适合）
- **第二层**：集成准备（最小可运行系统的搭建与验证）
- **第三层**：深入技术细节（进阶参考与性能调优）

**预计耗时**：第一层 5 分钟，第二层 2-4 小时，第三层按需查阅
**完成标志**：系统成功集成，硬件驱动通过测试，机械臂正常运动

## 完成标志

当你能够：
- ✅ 确认系统适配你的应用场景
- ✅ 完成最小可运行系统的搭建与验证
- ✅ 硬件驱动单独测试通过
- ✅ 机械臂能够完成基本运动（MoveJ 往返）

说明你已具备**成功集成本系统的全部能力**。
